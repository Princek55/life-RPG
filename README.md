# life-RPG
Life RPG is a gamified task-management web application built with HTML and powered by Supabase, an open-source backend service.
Unlike traditional to-do list apps, Life RPG makes completing daily tasks more engaging and rewarding. Users earn experience points (XP) each time they complete a task. As their XP increases, they level up, creating a sense of progress and motivation.
The application also includes a virtual currency system called UC. Users can earn UC by completing tasks or purchase it within the app. They can then use their UC to unlock themes, stickers, and other customization items from the in-app store.
Life RPG is my first project using a database and backend service. Supabase is used to manage features such as user data, tasks, XP, levels, virtual currency, purchases, and unlocked items.
